# やさしく学ぶ統計学 ― 記述統計から数理統計まで

[![Deploy](https://github.com/yasut0ra/learn-stats-ja/actions/workflows/deploy.yml/badge.svg)](https://github.com/yasut0ra/learn-stats-ja/actions/workflows/deploy.yml)

[![Code: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)

**初学者向けの統計学の無料教材です。図とシミュレーションで直感をつかみながら、数理統計学の基礎（推定・検定の理論）までしっかり学べます。**

📖 **サイトで読む → <https://yasut0ra.github.io/learn-stats-ja/>**

## 特徴

- **図が豊富**：120点以上の図で、数式の意味を「見て」理解できます。
- **動かして体感**：中心極限定理・信頼区間・検出力・最小二乗法・ベイズ更新などを、ブラウザで動くシミュレーションで体験できます。
- **数理統計までしっかり**：最尤法、フィッシャー情報量、クラメール・ラオの不等式、ネイマン・ピアソンの補題、尤度比検定まで、証明つきで扱います（証明は折りたたみ式なので、初学者は飛ばして読めます）。
- **練習問題つき**：全章に解答つきの練習問題があります。

## 統計検定との対応

[統計検定](https://www.toukei-kentei.jp/)の各級の出題範囲表と、この教材の各章の対応です。

- ◎：章の中心的な内容が、その級の出題範囲表に含まれる
- ○：一部の節だけが含まれる（どの節かは「補足」欄）
- 空欄：その級の出題範囲表には挙がっていない

上の級は下の級の内容を前提にしています（準1級は2級の範囲を含みます）。
空欄でも、上の級を受けるなら読んでおく必要があります。
また、◎ はその章で試験対策が十分という意味ではありません。

### この教材では扱っていない・手薄な範囲

受ける級に合わせて、公式テキストや過去問で補ってください。

- **3級**：時系列データ（時系列グラフ・指数・移動平均）、標本調査と実験の考え方
- **2級**：3級の項目をより詳しくしたもの（成長率・幾何平均・コレログラムなどの時系列データの処理、層化抽出・クラスター抽出などの標本抽出法、フィッシャーの3原則・ブロック化などの実験計画）に加えて、ローレンツ曲線・ジニ係数、偏相関係数、相関係数の区間推定
- **準1級**：確率母関数・包除原理、ワルド検定・スコア検定、カルバック・ライブラー情報量、ジャックナイフ法・ブートストラップ法、回帰診断の詳細（てこ比・Cook の距離など）と一般化線形モデル（ロジスティック回帰など）、実験計画法、標本調査法、多変量解析、時系列解析、マルコフ連鎖と確率過程、分割表のモデル、欠測データ、モデル選択（AIC など）。符号付き順位検定やクラスカル・ウォリス検定などは名前の紹介にとどまります
- **1級（統計数理）**：確率母関数、ワルド型・スコア型検定、カルバック・ライブラー情報量と AIC、共分散分析、欠測・打ち切りデータ、ブートストラップなど。1級は論述式なので、過去問で証明や導出を書く練習が欠かせません。分野別の **統計応用** は扱っていません

準1級の出題範囲表は **2027年1月1日** から改定され、概収束・分布収束、スルツキーの補題、バイアス・バリアンス分解、統計的因果推論などが加わります。
このうち収束の種類は第11章（11.7）、バイアス・バリアンス分解は第14章（定理14.1 MSE の分解）で扱っています。スルツキーの補題と統計的因果推論は扱っていません。
章ごとの対応表は、改定の前後で変わりません。

出典：統計検定の公式サイト（[3級](https://www.toukei-kentei.jp/exam/grade3/)・[2級](https://www.toukei-kentei.jp/exam/grade2/)・[準1級](https://www.toukei-kentei.jp/exam/grade1semi/)・[1級](https://www.toukei-kentei.jp/exam/grade1/)）で公開されている出題範囲表（2026年10月時点）。
範囲は改定されることがあるので、受験前に最新の範囲表を確認してください。

## ローカルで動かす

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

ブラウザで <http://127.0.0.1:8000/learn-stats-ja/> を開くとプレビューできます。

### 図を作り直す

本文の図（`docs/assets/figures/**/*.svg`）は `scripts/figures/` の Python スクリプトから生成しています。
日本語フォント（BIZ UDGothic、ヒラギノ角ゴシック、Noto Sans CJK JP、IPAex ゴシックのいずれか）が必要です。

```bash
python scripts/make_figures.py            # すべての図
python scripts/make_figures.py ch08 ch12  # 指定した章の図だけ
python scripts/make_tables.py             # 付録Bの数表
```

## ディレクトリ構成

